# Axon-Pose 🚀

>Sistema web en Django que utiliza visión artificial para monitorear y corregir en tiempo real la postura de adultos mayores durante sus ejercicios de equilibrio. 

---

## 📋 Características principales

* **Detección en tiempo real:** Capacidad de procesar [video / imágenes / streaming] de manera fluida.
* **Alta precisión:** Implementación de modelos avanzados para el seguimiento de puntos clave (Keypoints).
* **Fácil integración:** Diseñado de forma modular para adaptarse a diferentes pipelines de visión artificial.

---
